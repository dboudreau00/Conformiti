# CC6.2 - User provisioning

- **Framework:** SOC 2 2017 TSC (rev. 2022)
- **Category:** CC6 - Logical and Physical Access Controls
- **Control ID:** CC6.2
- **Owner:** _unassigned_
- **Review cadence:** annual

## Objective
New internal and external users are registered and authorised before access is granted.
